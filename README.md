#  Smart Farming Assistant

An AI-powered agriculture platform that helps farmers improve crop productivity through seed damage detection, crop recommendations, fertilizer suggestions, weather insights, and a farmer marketplace.

Project Demo : https://drive.google.com/file/d/1xBT2KZPwgudBqCvWbBTdpPyJn5dPVM1w/view?usp=drivesdk

Features ->

1. Seed Damage & Pest Detection

* Upload soybean seed images for analysis.
* Detect damaged seeds and pest infestations using AI.
* Display severity analysis with visual charts.
* Download inspection reports in CSV format.

2 .  Crop Recommendation System

* Suggest suitable crops based on:

  * Nitrogen (N)
  * Phosphorus (P)
  * Potassium (K)
  * Temperature
  * Humidity
  * Soil pH
  * Rainfall

3. AI Farming Assistant

* Integrated Gemini API for intelligent agricultural guidance.
* Answers farming-related queries.
* Provides recommendations and best practices.

4.   Real-Time Weather Monitoring

* Integrated OpenWeatherMap API.
* Displays current weather conditions.
* Helps farmers make informed agricultural decisions.

5.   Authentication & Security

* Secure user registration and login.
* Protected routes and user-specific data access.

6.  Farmer Marketplace

* Farmers can buy and sell agricultural products.
* Product listing and management.
* Marketplace for connecting buyers and sellers.
